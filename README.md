# Zyne Homepage Elegance

Build a premium static restaurant homepage for **ZYNE** — “Where Zest Meets Elegance.”

Use https://www.cagpride.com/ only as layout/UX inspiration. Do not copy it.

STYLE: Luxury, warm, cinematic, realistic fine-dining.

COLORS: Espresso #1F1A14, Brown #2A241C, Champagne Gold #D4AF57, Cream #F9F6EF, Beige #E8DCC6, White #FFF.

FONTS: Playfair Display + Inter.

NAV: ZYNE | Home | About | Menu | Experience | Gallery | Contact | Reserve a Table

HERO: Full-screen realistic luxury restaurant image, warm lighting, elegant tables.

Text: “WELCOME TO ZYNE” / “Where Zest Meets Elegance.”

Buttons: Reserve a Table / Explore Menu

SECTIONS:

• Intro — More Than Just a Meal

• ZYNE Values — Zest, Yearning, Nourishment, Elegance

• 3 Signature Dishes

• Dining Experience — Fine Dining, Private Dining, Celebrations

• Chef section

• 6-image Gallery

• 3 Testimonials

• Reservation CTA — “Your Table Awaits”

• Contact + Hours

• Footer

DESIGN: Editorial luxury, spacious, realistic photography, subtle gold accents, smooth scrolling, minimal animations, responsive mobile/desktop.

AVOID: Excessive black/gold, neon, cartoon graphics, excessive rounded cards, heavy animations, SaaS-style UI.

TECH: React + CSS, static frontend only. No backend/database/auth/payment.

**Build only the homepage. Prioritize visual quality and premium restaurant feel.**
